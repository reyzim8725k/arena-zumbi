ARENA ZUMBI - Sobrevivencia FPS

Como abrir:
  Clique duas vezes no index.html (funciona direto no navegador, sem instalar nada).

Como hospedar gratis:
  - GitHub Pages: crie um repositorio, envie o index.html e ative Settings > Pages.
  - Netlify: arraste a pasta inteira para app.netlify.com/drop.
  - Vercel: importe o repositorio ou arraste a pasta no painel.

Requisitos:
  Conexao com internet (o Three.js e carregado de um CDN).
